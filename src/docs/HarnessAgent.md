# 『ハーネスエージェント.md』: 実行環境ブリッジ & 検証レイヤー設計書

## 1. 概要
Windows 11 / NVIDIA RTX 3050 Ti (4GB VRAM) 環境における極限の軽量化・爆速描画・システム安定性を担保するためのブリッジおよびバリデーション仕様。

---

## 2. ハーネス構造とリソース制御

### 2.1 GPU/メモリガード (VRAM 4GB最適化)
- **ゼロWebGLアロケーション**:
  - 本システムでは重厚な3Dコンテキスト（WebGL / WebGPU）を一切起動せず、HTML5 2D Canvasのハードウェアアクセラレーションのみを使用。
  - VRAM消費量をわずか **30MB〜50MB** に抑え込み、他のグラフィック作業やローカルLLMへの影響を皆無にする。
- **ベクター直接描画 (ストリーミングパイプライン)**:
  - DXFエンティティ（LINE, ARC, CIRCLE, TEXT）を中間オブジェクトを経由せず、直接スクリーン行列変換してラスタライズ。
  - ガベージコレクション（GC）の発生頻度を極小化し、ズーム・パン時にも常に **60FPS** を維持。

### 2.2 DXF構文バリデーションハーネス
DXF出力直前に以下の整合性チェックを自動実行：
1. **グループコードの偶数行ペアリング**: コードと値が交互に出力されているか。
2. **終端EOFマーカー**: ファイル末尾に `0\r\nEOF\r\n` が存在するか。
3. **未定義レイヤーの排除**: 全エンティティが `TABLES` セクションで定義済みのレイヤーを参照しているか。
4. **文字コード安全性**: Jw_cad等のレガシーCADでも文字化けしない英数・標準文字の配置。

### 2.3 文字スケーリング品質バリデーションハーネス
1. **JIS最小高（2.5mm）ガード**: ペーパースペース出力時、文字高さが2.5mm未満のエンティティが存在しないかをアサーション。
2. **丸囲み記号マージン検査**: 通り芯記号（φ8.4mm）において、ラベル文字（3.0mm）が枠外にはみ出さない同心円クリアランスを担保。
3. **縮尺倍率整合性**: モデル空間エクスポート時、指定縮尺（600/300/200）と文字高倍率が厳密に一致していることを検証。

### 2.4 神社建築オントロジー整合性バリデーション
1. **様式不整合ガード**: 大社造における神明鳥居、寝殿造における両部鳥居など、歴史的・構造的整合性をチェック。
2. **柱間グリッド整合性**: 1間の寸法（2.4m〜5.5m）および柱数が、A2用紙境界内に正しく収まる幾何学的包含性を検証。
